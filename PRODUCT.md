# Product

## Register

brand

## Users

Peers and potential employers visiting Erik Scholtz's personal homepage to learn who he is and what he is working on.

## Product Purpose

A brief, readable personal introduction. Preserve the existing introduction and Pyrus description. The site is a normal browser page built with Ruby and Jekyll, hosted on GitHub Pages.

## Brand Personality

Quiet, mechanical, scholarly. The user-approved references are an ivory HHKB, terminal.shop's full-screen SSH interface, and academic papers. New Heterodox Mono is the primary voice; Inconsolata Nerd Font supports the terminal details.

## Anti-references

Avoid marketing cards, decorative animation, fake command execution, terminal loading sequences, and unnecessary controls. Do not add unprovided biographical claims or empty project and blog pages.

## Design Principles

- Make the introduction immediately readable.
- Express terminal character through alignment, frames, and small labels.
- Keep content compact and typography deliberate.
- Use ordinary browser links and semantic document structure.

## Accessibility & Inclusion

Target WCAG AA contrast, visible keyboard focus, responsive reflow, and full functionality without JavaScript. Decorative terminal marks are hidden from assistive technology.
